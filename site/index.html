gcpctx

Stop deploying to the wrong GCP project

Switch account, project, gcloud config, Application Default Credentials, and quota project as one safe context — with a venv-style prompt and guards for agents.

Install from npm GitHub 
npm install -g gcpctx
gcpctx shell-setup
gcpctx use prod
# prompt → (gcp:prod:your-project)
gcpctx assert --project your-project

Why gcloud config is not enough

Client libraries, Terraform providers, and many AI coding agents read Application Default Credentials — a separate global file. gcpctx keeps CLI + ADC aligned.

Aligned ADCPer-context credentials + quota project
Prompt(gcp:context:project) in zsh/bash/pwsh
Agent-safeassert / exec --require-context

Security posture

No telemetry. Credential bodies never printed. Allowlisted shell exports. Apache-2.0.
