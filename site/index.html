Stop deploying to the wrong GCP project

gcpctx switches account, project, gcloud config, ADC and quota project as one safe context.

npm install -g gcpctx
gcpctx shell-setup
gcpctx use prod
gcpctx assert --project my-prod

Why gcloud config is not enough

Client libraries use Application Default Credentials — a separate global file. gcpctx keeps CLI + ADC aligned.

Security

No telemetry. Credential bodies never printed. See SECURITY.md.
