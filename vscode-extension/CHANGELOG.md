# Change Log

All notable changes to the "gcpctx-skills" extension will be documented in this file.

## [1.0.1] - 2026-08-04

### Changed
- Document Open VSX and Visual Studio Marketplace install paths in Overview
- Point homepage to https://www.di2ops.com/products/gcpctx
- Align publisher id with marketplace listing (`di2ops`)

## [1.0.0] - 2026-08-01

### Added
- Initial release of gcpctx Skills extension
- Four AI skills for VSCode-based editors:
  - `gcpctx-usage`: Initialize and switch GCP contexts
  - `gcpctx-safety`: Safely manage production environments
  - `gcpctx-troubleshooting`: Diagnose and fix issues
  - `gcpctx-cicd`: Set up in CI/CD pipelines
- Commands:
  - `gcpctx.showSkills`: Display available skills
  - `gcpctx.openDocs`: Open documentation
- Compatible with GitHub Copilot, Continue, Windsurf, and other VSCode-based AI assistants
- Apache-2.0 licensed
